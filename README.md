# Christmas Hearth — Fireplace Screensaver

A full-screen Christmas living-room scene with a glowing fireplace, decorated evergreen tree, ornaments, warm string lights, stockings, garland, wrapped presents, a snowy night window, and subtle drifting snow.

## Features
- 1920 × 1080 animated Christmas fireplace scene.
- Decorated Christmas tree with lights, ornaments, and a star topper.
- Mantel garland, glowing bulbs, stockings, candles, and wrapped gifts.
- Snowy winter window and subtle indoor firelight.
- Press **D** to record and download a 25-second video with synthesized fireplace ambience.
- Video exports as WebM at 30 FPS for YouTube uploads.
- Press **F** for fullscreen and **H** to toggle controls.
- Audio starts after a user interaction because browsers restrict autoplay audio.

## Run locally
Open `index.html` in a recent version of Chrome or Edge. Click **Enable fireplace audio** once to activate sound.

## Cloudflare Worker
- Worker name: `fireplace`
- Health check: `/health`

The crackling audio is synthesized in-browser, not a field recording.
